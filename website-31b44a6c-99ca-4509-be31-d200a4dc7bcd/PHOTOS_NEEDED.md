## Image Optimization Tips

**Thumbnails (300x300px):**
- Use square aspect ratio
- Crop to showcase key subject
- File size target: 30-60KB

**Full versions (1200x900px or larger):**
- Maintain aspect ratio
- High quality (85-90% JPG quality)
- File size target: 120-200KB
